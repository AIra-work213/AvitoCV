# Решение тестового задания

### 1. Быстрый запуск воспроизводимости
#### Необходим python версии 3.12 и менеджер зависимостей uv
```bash
uv sync --frozen
```
После распаковки конкурсного архива структура должна выглядеть так:

```text
data/test/
├── sample_submission.csv
└── test/
    └── images/
        ├── test_00000.png
        ├── test_00001.png
        └── ...
```

Если все файлы находятся на своих местах, т.е. репозиторий был склонирован или скачан как архив (кроме тестовой выборки, ее необходимо вручную распаковать строго следуя структуре)  
То запустить воспроизведение можно следующей командой:
```bash 
uv run python scripts/create_submission_ocr_v5_meta.py
```
Это обучит финальную логистическую регрессию и сформирует файл сабмита.

### 2. Валидационная выборка
В качестве валидационной выборки использовались открытые данные и репозитория yandex-ocr.

Скачайте исходный Yandex-датасет:

```bash
uv run python scripts/download_yandex_ocr_wild.py
```

Сразу после завершения загрузки соберите финальную выборку из 553 строк:

```bash
uv run python scripts/prepare_yandex_ocr_real_lines_validation.py \
  --source data/train/rus_ocr_in_the_wild_dataset \
  --test-images data/test/test/images \
  --output data/train/yandex_ocr_real_long_lines_v4 \
  --samples 553 \
  --seed 20260926
```
